Ramyeon-sinusoidal function

A Sinusoidal function

Choice of Image & Parent Function:
I selected a photograph of ramyeon noodles because I frequently eat them for lunch near the Sunway convenience store. To find a real-world object to model, I observed small details around the campus. I noticed that the repetitive, wavy patterns of the noodles look remarkably similar to a periodic wave. Therefore, I chose the standard sine function, y=sin(x), as my parent function to capture this continuous, undulating shape.


Equation and Order of Transformations:
To precisely align the parent function with the actual flow, curves, and position of the noodle in the photograph, I applied transformations in the following mathematical order.

Vertical Stretch (Amplitude): The standard sine graph only oscillates between 1 and -1. Because the actual ripples of the noodle are much taller, I increased the amplitude by multiplying the function by a factor of 1.77.

Horizontal Reflection: To match the starting direction and the 'ups and downs' of the wave perfectly with the photo, I multiplied the x-coefficient by -1. This reflects the graph horizontally across the y-axis.

Horizontal Phase Shift: I translated the graph 0.9 units to the right to align the starting point of the wave with the visible noodle.

Vertical Translation: I shifted the entire graph 4.7 units down to position it correctly over the image axes.


Final Transformed Equation:
y = 1.77sin(-(x - 0.9)) - 4.7


Domain and Range Analysis:
Domain: D={x∈ℝ∣2≤x≤15}
I restricted the model strictly to the interval 2≤x≤15 because this represents the exact section of the noodle that is visible in the photograph. Outside of these endpoints, the graph would extend into empty space where no noodles are shown, rendering the model unrealistic.

Range: R={y∈ℝ∣-6.47≤y≤-2.93}
Since a sinusoidal function is continuous and oscillates symmetrically around its midline, its behavior and range are determined entirely by its vertical parameters rather than its domain endpoints. The vertical translation shifts the midline of the wave down to y=-4.7. The vertical stretch extends the peaks and troughs of the wave 1.77 units above and below this midline. Therefore, the minimum value is calculated as -4.7-1.77=-6.47, and the maximum value is -4.7+1.77=-2.93.


Comparison with Parent Function:
Compared to the parent function y=sin(x) which has an amplitude of 1, a period of 2π, a midline at y=0 and passes through the origin (0,0) moving upwards—this transformed model is vertically stretched, flows in the opposite horizontal direction due to the y-axis reflection, and has been shifted both horizontally and vertically into the fourth quadrant to accurately mimic the physical structure of the ramyeon.

Sculpture-secant function

A Secant function

Parent Function: y = secx

Transformation:
- This resulted in the function y = 1.77(sec(-0.5(x-7)) - 0.8) which closely models the U-shape in the photograph. Compared to the parent function, this graph has been vertically stretched by a factor of 1.77.
- It is horizontally stretched by a factor of 2 (due to the 0.5 coefficient) and reflected across the y-axis (due to the negative sign).
- Finally, it is translated 7 units to the right and shifted down by 1.416 units (1.77 * -0.8).

Summary of Transformation:
y = secx

Domain and Range:
Domain: The domain of my function is {x∈&Real; | 7-π < x < 7+π}, (which simplifies from -π/2 < -0.5(x-7) < π/2). I restricted the model to this interval to capture exactly one continuous U-shaped branch of the secant function. Outside of this interval, the graph would create repeated branches and vertical asymptotes that do not exist on the real sculpture.
Range: By evaluating the function at the lowest point of the curve (x = 7), I obtained the minimum y-value of 0.354 since 1.77(sec(0) - 0.8) = 1.77(1 - 0.8) = 0.354. As the graph approaches the boundaries of the domain, the y-values increase infinitely toward positive infinity. Therefore, the theoretical range is {y∈&Real; | y ≥ 0.354}.

Bookshelf-inverse square function

An Inverse square function

Parent function: y = 1/x2

Transformation:
This resulted in the function: y = 1.2/x2 + 0.2 which closely models the shape in the photograph. Compared to the parent function, this graph has been vertically stretched by a factor of 1.2 and vertically translated upwards by 0.2 units.

Summary of transformation:
y = 1.2/x2 + 0.2

Domain & Range:
Domain: The domain of my function is {x∈&Real; | -6 < x < 6}, x≠0 because I restricted the model to the section of the bookshelf that is visible in the photograph. Outside of this interval, the graph would represent parts of the bookshelf that are not shown, so the model would no longer reflect the real situation. Additionally, x = 0 is excluded because the function is undefined at this point.
Range: By evaluating the function at the endpoints of the domain (x = ±6), I obtained the minimum y-value of approximately 0.233. As x approaches 0, the y-value increases infinitely. However, because I restricted the model to the physical boundaries of the photograph, the upper bound is capped at 8. Therefore, the range of the function is {y∈&Real; | 0.233 ≤ y < 8}.

Traffic signal post-rational function

A Rational function

Transformation:
I chose this photograph because the curved shape of the traffic signal post closely resembled a rational function. To model the traffic signal post appearing in the image, I began by identifying that its shape was similar to the parent rational function y = 1/x as a starting point.

From observing the orientation of the curve in my image, I noticed that the graph was decreasing from left to right rather than increasing. This indicated a reflection across the x-axis. Therefore, I modified the function to y = -1/x to match the direction of the curve.

Initially, I found it difficult to determine the correct vertical stretch or compression factor because the graph in the image was positioned away from the origin, making it challenging to accurately compare the steepness. To address this, I temporarily focused on aligning the asymptotes first so I could analyse the shape without the added complexity of translations. By comparing the curvature of the graph with the traffic signal post, I determined that a vertical compression was needed rather than a stretch, and refined the value through observation until the curve closely matched the image.

Once the shape was established, I returned the graph to its original position by applying translations. I shifted the graph horizontally to align the vertical asymptote with the position where the traffic signal post begins in the image and then applied a vertical translation so the curve passed through key points on the traffic light structure. This resulted in the function y = -0.2/(x-1.9) + 7.7 which closely models the shape of the traffic signal post in the photograph.

Summary of transformation:
- Reflection across the x-axis: 1/x → -1/x
- Vertical compression of factor 0.2: -1/x → -0.2/x
- Horizontal translation of 1.9 units to the right: -0.2/x → -0.2/(x-1.9)
- Vertical translation of 7.7 units upward: -0.2/(x-1.9) → -0.2/(x-1.9)+7.7

Domain & Range:
Domain: The domain of my function is D:{x∈&Real; | 1.933 ≤ x ≤ 7.8}. I limited the domain to the portion of the traffic signal post that was visible in the photograph. In hindsight, I would have taken the picture so that it included more of the curve, allowing me to model a larger section of the structure rather than only the visible part. As a result, my model is only valid for the section of the traffic signal post captured in the image. (The parent function y = 1/x has a domain of D:{x∈&Real; | x ≠ 0} and a range of R:{y∈&Real; | y ≠ 0}).

Range: Transformed function contains asymptotes at vertical x = 1.9 and horizontal y = 7.7. Since I restricted the domain to a small interval entirely to the right of the vertical asymptote, the discontinuity is not visible in my model. Since the function is continuous on the restricted interval, the range can be determined by evaluating the function at the endpoints of the domain. By evaluating the function near x = 1.933 and at x = 7.8, I obtained approximate output values between 1.64 and 7.67. Therefore, the range of the function is approximately R:{y∈&Real; | 1.64 ≤ y ≤ 7.67}.
